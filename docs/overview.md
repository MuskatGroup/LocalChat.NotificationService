# NotificationService — обзор

## Ответственность

- принять доменное событие и выбрать канал доставки;
- **не включать plaintext** сообщений в push (только «новое сообщение» / conversation id);
- уведомить пользователя об approve/reject заявки;
- хранить device push tokens (или получать из Identity/Web).

## Что сервис НЕ делает

- не является чатом и не хранит историю;
- не расшифровывает E2EE;
- не подтверждает заявки (это Identity + Admin).
